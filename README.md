# Эмулкон

Эмулятор подключаемого оборудования для «Библиотеки подключаемого оборудования» (БПО):
драйвер для 1С плюс сервер эмуляции с моделями устройств, сценариями сбоев и журналом обменов.

Эта копия исходного кода входит в поставку с площадки публикации. Здесь же — установщик,
драйвер и инструкция (`УСТАНОВКА.txt`).

## Что внутри

| Каталог | Содержимое |
|---|---|
| `server/` | сервер эмуляции (Go, без внешних зависимостей) |
| `component/` | драйвер для 1С (C++17, Native API, x64/x86) |
| `tray/` | приложение в трее у кассы |
| `console/` | консоль MMC |
| `setup/` | установщик |
| `docs/` | протокол, модели устройств, контракт БПО, установка |
| `tests/1c/` | прогоны в типовых конфигурациях и отчёт `RESULTS.md` |
| `deploy/` | Docker, пакеты Linux |

Подробное описание устройства — `ARCHITECTURE.md`, история версий — `CHANGELOG.md`.

## Сборка

| Часть | Язык | Команда |
|---|---|---|
| сервер | Go 1.24+ | `cd server && go build ./... && go test ./...` |
| драйвер, трей, консоль, установщик | C++17, clang-cl (ABI MSVC), CMake + Ninja | `.\build.ps1` в корне — всё сразу в `dist\` |

SDK Native API 1С в поставку не входит: он распространяется фирмой «1С». Путь к каталогу
`include` задаётся переменной `ONEC_SDK` или ключом `-DONEC_SDK=…` при конфигурировании CMake.

## Ограничения

Эмулкон предназначен для разработки, отладки и тестирования: он изображает оборудование и
принимает только тестовые данные. Реальные номера карт и ПИН не принимаются и не хранятся.
Для реальной фискализации нужно настоящее оборудование.
