# Проверка драйвера в 1С под Linux

Драйвер Эмулкона собирается и под Linux (`libEmulkonDriver_lin64.so`, x86_64): CI собирает его в manylinux_2_28 (glibc 2.28)
и прогоняет модульные тесты и стенд «как платформа 1С» — без сервера и на живом сервере. Здесь — проверка
в **настоящей 1С под Linux**: тестовая ВМ Hyper-V на машине разработчика.

> Скрипты подготовлены, но ещё **не запускались**: нужны права администратора (UAC), скачивание образа и
> дистрибутив платформы 1С для Linux.

## Что понадобится

- Windows с Hyper-V (на машине разработки он есть), ~70 ГБ на диске, 8 ГБ памяти для ВМ.
- Дистрибутив платформы 1С:Предприятие для Linux с ИТС: `setup-full-<версия>-x86_64.run` (8.3.20 и новее) или
  deb-пакеты — и способ лицензирования в ВМ (программная лицензия, ключ, сервер лицензий).
- Выгрузка тестовой базы (`.dt`) с БПО — например, та же, что для прогонов на Windows (`tests/1c`).

## Шаги

1. **ВМ.** PowerShell от имени администратора:
   ```powershell
   tests\linux\new-vm.ps1 -List   # какие Ubuntu есть в галерее Hyper-V
   tests\linux\new-vm.ps1         # скачать образ галереи (~2 ГБ, SHA-256 сверяется), создать и запустить ВМ
   ```
   Образ — из галереи «Быстрое создание» Hyper-V (Microsoft): Ubuntu с рабочим столом и расширенным сеансом.
   В окне ВМ один раз пройти мастер Ubuntu (язык, пользователь). Снимок «чистая Ubuntu» создаётся сразу —
   к нему можно откатиться.
2. **Файлы в ВМ** — с компьютера (Guest Services включены):
   ```powershell
   Copy-VMFile EmulkonLinux -SourcePath <дистрибутив 1С> -DestinationPath /home/<пользователь>/1c/ -FileSource Host -CreateFullPath
   Copy-VMFile EmulkonLinux -SourcePath tests\linux\install-1c.sh -DestinationPath /home/<пользователь>/ -FileSource Host
   Copy-VMFile EmulkonLinux -SourcePath tests\linux\check-driver.sh -DestinationPath /home/<пользователь>/ -FileSource Host
   ```
3. **Платформа 1С** — в ВМ: `sudo bash install-1c.sh ~/1c`, затем лицензия.
4. **Сервер Эмулкона для ВМ.** Служба на компьютере слушает только себя: включите «Кассы в сети» (консоль
   «Эмулкон» → Служба → Свойства). Адрес компьютера для ВМ — адрес адаптера `vEthernet (Default Switch)`.
   Проверка из ВМ: `bash check-driver.sh http://<адрес>:8737` — скачает пакет драйвера, сверит SHA-256 и
   найдёт в нём библиотеку Linux.
5. **В 1С** (база из `.dt`): «Подключение и настройка оборудования» → «Драйверы оборудования» → «Добавить новый
   драйвер из файла» (`~/emulkon/EmulkonDriver_<версия>.zip`), экземпляр ККТ с адресом сервера, «Тест
   устройства», чек, затем остальные типы — как в `tests/1c/README.md`.
6. **Что записать:** версии Ubuntu, платформы, БПО, результат по типам оборудования; журнал сервера
   (консоль → Журнал → «Выгрузить журнал…»).

## Что проверяем именно на Linux

- Загрузка `.so` платформой (`MANIFEST.XML`, `os="Linux"`) и ABI: те же методы, что и на Windows.
- HTTP-клиент на сокетах: сессии, команды, поток событий (сканер, весы, экран терминала).
- Самообновление: кэш `~/.cache/emulkon/driver/<версия>/`, переадресация через `dlopen` после перезапуска 1С.
- База из командной строки (`/proc/self/cmdline`), имя компьютера (`gethostname`).

После проверки — `tests\linux\new-vm.ps1 -Remove` или откат к снимку «чистая Ubuntu».
