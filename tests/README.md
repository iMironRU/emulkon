# Тесты

- **Модульные и интеграционные тесты сервера** живут рядом с кодом (`server/internal/**/_test.go`,
  сквозной сценарий — `server/internal/app/app_test.go`): `cd server && go test ./...`.
- `server/` — место для внешних (black-box) проверок развёрнутого сервера: HTTP-сценарии, нагрузка.
- `e2e/` — тестовая конфигурация 1С на БПО и сценарии (Vanessa или аналог): драйвер выбирается
  в БПО, подключается, проходит тест устройства, выполняет методы через сервер (критерий этапа 1).
