# Устройства ввода (раздел 3.8): сканер штрихкода, считыватель магнитных карт

Источники:
- **[Т]** «Требования к разработке драйверов подключаемого оборудования» 4.8, раздел 3.8;
- **[Д]** БПО 3.3.4.30, `CommonModules\ПодключаемоеОборудованиеДрайверКлиент`;
- **[Ф]** там же, `Catalogs\ПодключаемоеОборудование\Forms\ФормаНастройки` (дорожки считывателя);
- **[П]** там же, `МенеджерОборудованияПовтИсп.СоответствиеТиповОборудования`.

Сверено 2026-10-08.

## Методов нет — только события

Своих методов у драйверов устройств ввода нет [Т]. На каждое считывание драйвер вызывает
`ExternalEvent(bstrWho, bstrWhat, bstrData)` у интерфейса платформы, полученного в `Init`.
Длину очереди задаёт `SetEventBufferDepth`; при переполнении платформа новые события отбрасывает.

- **bstrWho** — идентификатор подключённого устройства. БПО ищет подключение по
  `ИДУстройства = Источник` — это DeviceID из `ConnectEquipment`.
- **bstrWhat** — тип данных, RU или EN:

| bstrWhat | Данные |
|---|---|
| Штрихкод / Barcode | штрихкод строкой |
| ШтрихкодBase64 / BarcodeBase64 | штрихкод в Base64 |
| ДанныеКарты / TracksData | данные дорожек строкой |
| ДанныеКартыBase64 / TracksDataBase64 | данные дорожек в Base64 |
| НажатиеКлавиши / KeyPress | клавиша терминала сбора данных |
| RFIDData | метка RFID на ТСД: `TID;EPC;UserMemory` в HEX |
| ОшибкаДрайвера / DriverError | текст ошибки устройства |

**Какие события БПО слушает** ([Д]:883–911, после подключения): сканер — Штрихкод, ШтрихкодBase64,
Barcode, BarcodeBase64, НажатиеКлавиши, KeyPress; считыватель магнитных карт — ДанныеКарты,
ДанныеКартыBase64, TracksData, TracksDataBase64; RFID — `RFID`; весы — Взвешивание/Weighting (если
`WeighingEvent`); дисплей покупателя — Нажатие/OnClick (если дисплей отрабатывает нажатия). Разбор —
`ОбработатьСобытие` ([Д]:1508).

- Штрихкод: `Штрихкод = СокрЛП(Данные)`. У Base64-варианта БПО не декодирует данные здесь — отдаёт
  дальше как есть ([Д]:1308).
- **Данные карты** ([Д]:1373): БПО режет строку по настройке дорожек экземпляра — для каждой
  используемой дорожки ищет её префикс и суффикс (коды символов) и собирает `КодКарты`. По умолчанию
  ([Ф]:36–43) используется только **дорожка 2, префикс 0, суффикс 13 (CR)**.

## Тип «считыватель карт»

Таблица типов [Т] называет его `CardReader` / **СчитывательКарт**, но БПО сопоставляет строку типа
с именем значения перечисления — **СчитывательМагнитныхКарт** — или с английским `CardReader` ([П]).
Русское «СчитывательКарт» БПО 3.3.4.30 не узнает: в INFO.XML пишем `СчитывательМагнитныхКарт`.
Так же тип приходит и в `ConnectEquipment` (`XMLСтрока` перечисления).
