# Считыватель RFID (раздел 3.10): сессия, пакеты меток, запись

Источники: **[Т]** требования 4.8, раздел 3.10; **[Д]** БПО 3.3.4.30,
`ПодключаемоеОборудованиеДрайверКлиент` (:1439, :5317–5445). Сверено 2026-10-08.

| Англ. | Рус. (вызов в [Д]) | Параметры | Возврат |
|---|---|---|---|
| OpenSessionRFID | ОткрытьСессиюRFID (:5354) | 0 DeviceID | BOOL |
| CloseSessionRFID | ЗакрытьСессиюRFID (:5377) | 0 DeviceID | BOOL |
| GetDataTagsRFID | ПолучитьДанныеМетокRFID (:5328) | 0 DeviceID · 1 PackageID STRING · 2 TagsTable STRING **out** (XML) | BOOL |
| SaveDataTagRFID | ЗаписатьДанныеВМеткуRFID (:5407) | 0 DeviceID · 1 TID STRING in/out · 2 EPC STRING in/out · 3 Data STRING · 4 MemoryBank LONG (1 — EPC, 2 — USER) · 5 Timeout LONG | BOOL |

**Как читаются метки** [Т]: при открытой сессии о новых метках в зоне антенны драйвер сообщает
внешним событием `ExternalEvent(DeviceID, "RFID", <идентификатор пакета>)`. 1С по нему вызывает
`ПолучитьДанныеМетокRFID` — этот вызов и есть подтверждение доставки. В [Д]:1446 он
**синхронный** (без `Асинх`), прямо из обработки события. Ошибка — `ОшибкаДрайвера` /
`DriverError` с текстом в bstrData.

**TagsTable** — `<Table><Tag TID EPC USER/></Table>`: банки памяти в HEX; `USER` необязателен.

Запись — в рамках открытой сессии, метка ищется по TID и EPC; банк — EPC или USER MEMORY.

Открытый вопрос: в [Д] есть `СгенерироватьВнешнееСобытие(ДанныеСобытия, Base64)` (:5433) —
«команда допустима только для эмулятора драйвера» (поставляемые эмуляторы 1С). В требованиях её
нет, DeviceID она не получает — эмулятор её не реализует (ARCHITECTURE §13).
