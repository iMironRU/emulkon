# Принтер чеков (раздел 3.6) и принтер этикеток (раздел 3.7): методы, XML

Источники — как у ККТ ([kkt-methods.md](kkt-methods.md)):
- **[Т]** «Требования к разработке драйверов подключаемого оборудования» 4.8, разделы 3.6 и 3.7;
- **[Д]** БПО 3.3.4.30, `CommonModules\ПодключаемоеОборудованиеДрайверКлиент`;
- **[Ч]** там же, `ОборудованиеЧекопечатающиеУстройстваКлиентСервер` и `ОборудованиеЧекопечатающиеУстройства`
  (сборка DocumentPackage);
- **[Э]** там же, `ОборудованиеПринтерыЭтикеток` (сборка пакетов этикеток).

Сверено 2026-10-08.

## Принтер чеков (ПринтерЧеков, ReceiptPrinter)

Нефискальный принтер: печать текстовых документов со штрихкодами и денежный ящик. Методы те же,
что у ККТ (раздел 3.5), с теми же позициями:

| Англ. | Рус. (вызов в [Д]) | Параметры | Возврат |
|---|---|---|---|
| PrintTextDocument | НапечататьТекстовыйДокумент (:2710) | 0 DeviceID · 1 DocumentPackage STRING in (XML) | BOOL |
| OpenCashDrawer | ОткрытьДенежныйЯщик (:2906) | 0 DeviceID | BOOL |
| GetLineLength | ПолучитьШиринуСтроки (:2462) | 0 DeviceID · 1 LineLength LONG **out** | BOOL |

- «Печать чека» на принтере чеков — это `НапечататьТекстовыйДокумент`: в `ФискализацияЧека`
  ветка `ПринтерЧеков` вызывает `ПечатьТекста` ([Д]:2492). Документы разделены по `[отрезка]`
  на отдельные пакеты ещё в 1С ([Ч]:1890).
- `ПолучитьШиринуСтроки` БПО зовёт сразу после подключения ККТ и принтера чеков ([Д]:847–850) и
  запоминает ширину.
- Флаг `ТипыОборудования.ПринтерЧеков` в БПО — тип **экземпляра** (запись справочника драйверов
  заводится на каждый тип из INFO.XML; `ДрайверыОборудования` :255), поэтому драйвер может
  объявить и ККТ, и принтер чеков: фискализация ККТ в ветку принтера не уйдёт.

**DocumentPackage** — `<Document><Positions><TextString Text/><Barcode …/></Positions></Document>`
([Т] 3.6). Штрихкод по ревизии драйвера ([Ч]:1999–2015):

| Ревизия | Атрибуты Barcode |
|---|---|
| ≥ 3003 (у эмулятора 4008) | `Type`, `ValueBase64` |
| 3000–3002 (только ККТ) | `Type`, `Value` |
| < 3000 | `BarcodeType`, `Barcode` (так и в примере [Т]) |

Типы штрихкода [Т] 3.6: EAN8, EAN13, EAN128, CODE39, Code128, Code16k, Code93, PDF417, DataMatrix,
QR, ITF14, EAN13Addon2, EAN13Addon5, GS1DataBarExpandedStacked. Если модель не печатает такой тип —
драйвер возвращает ошибку.

## Принтер этикеток (ПринтерЭтикеток, LabelPrinter)

| Англ. | Рус. (вызов в [Д]) | Параметры | Возврат |
|---|---|---|---|
| InitializePrinter | ИнициализацияПринтера (:5260) | 0 DeviceID | BOOL |
| PrintLabels | ПечатьЭтикеток (:5295) | 0 DeviceID · 1 LabelsTable STRING in (XML) · 2 PackageStatus STRING in | BOOL |

- `ИнициализацияПринтера` — отдельная команда (`ОборудованиеПринтерыЭтикетокКлиент`), перед печатью
  её не зовут.
- **Пакеты** ([Э]:962, [Д]:5284–5290): по 200 этикеток. Разметка (`Formatting`) — только в первом
  пакете задания, `Labels` — в каждом. Статусы считает [Д]: пакет 0 — `first`, пакеты с номером
  больше 1 — `regular`, последний — `last`. **Пакет 1 тоже уходит со статусом `first`**: задание из
  трёх пакетов приходит как `first`, `first`, `last`. Один пакет — `last`.

**LabelsTable** — `<Data><Formatting …/><Labels>…</Labels></Data>`:

| Элемент | Атрибуты | |
|---|---|---|
| Formatting | Width, Height (мм) | шаблон этикетки |
| Formatting/Text | FieldName, Left, Top, Width, Height (мм), Orientation, FontName, FontSize, FontStyle (`Bold Italic Underline StrikeOut`), Border, BorderWidth, BorderStyle, Align, VAlign, Multiline, Static, Value | текст |
| Formatting/Barcode | FieldName, Type, Left, Top, Width, Height, Orientation, PrintHRI, FontSize, CheckSymbol, Static, ValueBase64 | штрихкод |
| Formatting/Image | FieldName, Left, Top, Width, Height, Orientation, Border…, Static, Value (Base64) | картинка |
| Formatting/UserData | FieldName, Static, Value | данные для драйвера, не печатаются |
| Labels/Label | Quantity (по умолчанию 1) | этикетка и число копий |
| Labels/Label/Record | FieldName, Value | значение поля; у картинки — Base64 |

- `Static="true"` — значение общее для всех этикеток (из `Formatting`); иначе `Value` в шаблоне —
  значение по умолчанию, когда у этикетки нет `Record`.
- Типы штрихкода [Т] 3.7: EAN8, EAN13, EAN128, Code39, Code128, Code16k, Code93, PDF417, DataMatrix,
  **QRCode**, ITF14, EAN13Addon2, EAN13Addon5, GS1DataBarExpandedStacked.
- **Штрихкод в `Record`**: [Э] пишет `ValueBase64` только при ревизии > 3002, но
  `ПодготовитьПакетыДляПринтераЭтикеток` вызывает сборку без ревизии ([Э]:984) — на практике
  штрихкод приходит открытым текстом в `Value`. Разбирать оба.
- Числа [Э] пишет с точкой (`ЧРД=.`). Шаблон этикетки в БПО хранится в своём формате
  (`СохранитьXMLФайл`: `TypeFill`, `Format`, `Background`, координаты с 1), в драйвер уходит уже
  пересчитанный: координаты с 0, поворот шаблона учтён в `Orientation` полей.
