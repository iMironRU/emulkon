# Модель терминала сбора данных (эмулятор)

Код — `server/internal/models/tsd`. Контракт — [tsd.md](../bpo-requirements/tsd.md).

**Исходное состояние:** товаров нет, документ пуст.

| Метод | Что делает |
|---|---|
| UploadTable | новая выгрузка начинается с `first` или с любого пакета после `last`; `FullLoad="true"` её первого пакета очищает товары. Записи дополняют таблицу: тот же штрихкод с той же характеристикой и серией заменяется |
| DownloadTable | собранный документ: `BarCodeBase64`, `Quantity`, `ContainerBarCodeBase64`. Документ остаётся в терминале |
| ClearTable | очищает таблицу товаров; собранный документ остаётся (очищается в панели) |

| Код | Текст | Когда |
|---|---|---|
| 87 | Неверный статус пакета | не `first`, `regular`, `last` |
| 98, 99 | | пустой или неразборчивый пакет, нет `BarCodeBase64`, не Base64 |

**Документ собирают в панели управления**: действие `collect` `{"barcode", "quantity"}` —
количество добавляется к строке с тем же штрихкодом (имя — из таблицы товаров, если штрихкод
там есть); `remove` `{"barcode"}`; `clear_document`.

В состоянии: `goods` (первые 500), `goods_count`, `upload` (пакетов, записей, полная ли, статус),
`document`, `downloads`.
