# История версий

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Версия одна на всё (сервер, драйвер, трей, консоль, установщик) — файл [VERSION](VERSION).

## [Не выпущено]

### Исправлено
- **Обновление из открытой консоли не обрывается на полпути** (#24): файлы Эмулкона держит программа, которую
  установщик не закрывает (консоль MMC, 1С), — «Перед установкой» называет её («консоль «Эмулкон» (mmc.exe)») до
  остановки службы; закрыли — «Проверить снова». Раньше служба останавливалась, а установка падала на замене
  `EmulkonSnapIn.dll` с советом закрыть трей.

### Изменено
- **Консоль: в окне новой версии — кликабельная ссылка «Что нового»** (#25) на страницу выпуска со списком
  изменений; кнопки «Скачать и установить» и «Отмена» (TaskDialog).

## [0.9.1] — 2026-10-18

Установщик, который не тревожит Defender, и обновления из трея: служба сообщает о новой версии, трей скачивает
и запускает мастер.

### Добавлено
- **Новые версии — сами** (#8): служба раз в сутки проверяет выпуск на GitHub и сообщает; трей показывает «Вышла
  версия X», а по «Обновить до X…» качает установщик в «Загрузки» (метка «из Интернета», сверка размера и SHA-256) и
  запускает мастер обновления (UAC); веб-интерфейс показывает плашку. `UpdateMode` (`off` / `notify`), `UpdateURL`;
  `GET /api/v1/updates`, `POST /control/v1/updates/check`; журнал — `update.check`, `update.available`. Служба
  установщик не качает (#20).
- **Драйвер Linux ARM64 — сборка и тесты в CI** (#12): ARM-раннер GitHub, manylinux_2_28_aarch64, те же модульные
  тесты и стенд на живом сервере. В пакет драйвера пока не входит — ждём подтверждения `arch` для Linux ARM в 1С.

### Исправлено
- **Установщик больше не похож на вредонос для Defender** (#20, `Behavior:Win32/DefenseEvasion.A!ml`): брандмауэр —
  через API Windows, а не скрытый `netsh`; трей и сервер закрываются через Restart Manager, без `SeDebugPrivilege`;
  занятые файлы не переименовываются; деинсталлятор удаляет себя при перезагрузке, без `cmd`. Консоль качает
  обновление в «Загрузки» с меткой «из Интернета», а не в `ProgramData`.
- Страница загрузок не отвечает HTTP 500, если файл пропал во время обхода (забран антивирусом) — пропускает его.
- Драйвер называет серверу архитектуру по компилятору (`x86_64`, `i386`, `aarch64`), а не по разрядности: сборка ARM64
  не назовётся x86_64 и не получит чужую библиотеку самообновления; сервер принимает `arch=aarch64`.

### Изменено
- **Консоль: окно новой версии короче** (#21): вместо списка изменений — «Нет» открывает «Что нового» на странице
  выпуска.
- **Драйвер подсказывает, что делать без сервера** (#14): ошибка «Нет связи с сервером эмуляции» говорит, по какому
  адресу искали, и для этого компьютера — поставить Эмулкон или указать общий сервер команды, для другого адреса —
  проверить, что сервер запущен и открыт для касс в сети.
- **Сборки не для выпуска** (#10): к имени библиотеки драйвера в пакете добавляется начало её SHA-256 — новая
  сборка той же версии ставится в 1С без ручной чистки `ExtCompT`; выпуск (`build.ps1 -Release`) — имена как прежде.

## [0.9.0] — 2026-10-17

Эмулкон под Linux: драйвер для 1С (проверен в настоящей 1С), сервер пакетами `.deb`/`.rpm` и образом Docker;
в консоли — проверка обновлений и перенос настроек.

### Добавлено
- **Драйвер для Linux x86_64** (`libEmulkonDriver_<версия>_lin64.so`) в общем пакете драйвера (`os="Linux"`
  в `MANIFEST.XML`) и в установщике: та же кодовая база, HTTP на сокетах, без внешних зависимостей
  (glibc 2.28+). Самообновление на Linux — кэш `~/.cache/emulkon/driver/`.
- Сервер отдаёт обновление драйвера по ОС (`os=` в проверке обновления), журнал пишет `driver_os`.
- CI собирает драйвер Linux и прогоняет те же тесты, что на Windows, включая стенд на живом сервере.
- **Сервер для Linux пакетом** — `emulkon_<версия>-1_amd64.deb` и `emulkon-<версия>-1.x86_64.rpm`: служба systemd
  `emulkon`, настройки в `/etc/emulkon/emulkon.env`, данные в `/var/lib/emulkon`, драйвер для касс внутри
  ([deploy/linux](deploy/linux/README.md)). CI ставит пакеты на чистую Ubuntu и в Rocky Linux 9.
- **Консоль: «Проверить обновления…»** — последний выпуск на GitHub, что нового, скачать с проверкой SHA-256 и
  запустить мастер обновления. Релиз публикует описание выпуска `latest.json`.
- **Консоль: выгрузить и загрузить настройки службы** — перенос на другой компьютер одним файлом JSON
  (токенов в нём нет, только SHA-256).

- **Образ Docker в GHCR** — `ghcr.io/imironru/emulkon:<версия>`: общий сервер для команды разработчиков, драйвер для
  касс внутри (страница загрузок и самообновление). CI собирает и проверяет образ, релиз публикует.

### Исправлено
- **Драйвер под Linux: дробные числа при русской локали.** Клиент 1С под Linux включает локаль системы (десятичная
  запятая), и вес с весов приходил в 1С нулём. Числа JSON теперь пишутся и читаются без локали.
- Изменение подписи, заметки и вывода устройства и рабочего места пишется в журнал (`control.device_meta`,
  `control.workstation_meta`).

### Проверено
- **Драйвер в 1С под Linux**: УНФ 3.0 на платформе 8.5.1.1529, Ubuntu 24.04 — 128 из 128 шагов, все 12 типов
  оборудования ([tests/1c/RESULTS.md](tests/1c/RESULTS.md), порядок — [tests/linux](tests/linux/README.md)).
- **Перекрёстные связки:** 1С под Linux — сервер на Windows (служба) и 1С на Windows (УНФ 3.0, 8.5.1.1529) — сервер на
  Linux (пакет `.deb`, служба systemd): обе 128 из 128.

## [0.8.0] — 2026-10-15

Первый публичный релиз: исходники — по лицензии Apache-2.0, сборка и тесты — в GitHub Actions на каждый push,
релизы — по тегу с установщиком, пакетом драйвера и `SHA256SUMS`.

### Добавлено
- **Установка на машину**: сервер — служба Windows «Emulkon» (LocalService, автозапуск, перезапуск при сбое),
  данные в `ProgramData`, настройки в реестре, журнал событий Windows, правило брандмауэра для касс в сети.
- **Мастер обслуживания** в «Установленных приложениях»: изменить, восстановить, удалить; перенос прежней установки
  из профиля пользователя.
- **Трей управляет службой**: запуск, остановка, перезапуск без UAC.
- **Элемент Панели управления** «Эмулкон».
- **Консоль MMC** «Эмулкон»: сводка; служба — запуск и остановка, сервер для касс в сети, токены управления и
  устройств (показываются один раз, хранится SHA-256); рабочие места и их токены; устройства — подпись, сброс,
  удаление; сценарии — включить, выключить, выгрузить и загрузить; журнал — отбор и выгрузка.
- Токены сервера можно задать хешем SHA-256 (реестр, переменные `EMULKON_*_TOKEN_HASH`).

### Проверено
- Прогоны на 11 конфигурациях 1С: Розница 2.3 и 3.0, УНФ 3.0, РМК 1.1, УТ 10.3 и 11, КА 2.6, БП 3.0, БГУ 2.0
  ([tests/1c/RESULTS.md](tests/1c/RESULTS.md)).
