Драйвер для 1С

Общий архив — все типы сразу: «Загрузить новый драйвер из файла» создаёт в справочнике «Драйверы оборудования» по записи на каждый тип из архива. Нужен один тип — скачайте архив из его карточки ниже. Типы, которых не было в загруженной раньше версии, появляются только после новой загрузки архива: «Обновить драйвер» в карточке обновляет компоненту, но новых записей не создаёт. Сама компонента обновляется сама: при подключении узнаёт у сервера о новой версии, скачивает её и переходит на неё после перезапуска 1С. Проверить вручную — кнопка «Проверить обновление драйвера» в форме настройки экземпляра.

Требования

  • 1С:Предприятие 8.3 на Windows (тонкий, толстый клиент), x64 или x86.
  • БПО с требованиями к драйверам 4.8 (ревизия интерфейса 4008) — например, БПО 3.3.
  • Сервер — Windows (установщик) или Docker. Linux-версия драйвера — позже.

Установить Эмулкон на другой компьютер

Сервер эмуляции и трей: чеки и этикетки, экраны терминала и весов. Без прав администратора, удаляется через «Установленные приложения», перед установкой и после неё проверяет, что всё работает.
